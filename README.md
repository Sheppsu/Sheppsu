### Welcome to my profile

I'm a college student and have been programming since around 2017 (mostly self-taught). I'm an undergrad majoring in statistics and data science math.

I like doing projects in relation to the game [osu!](https://github.com/ppy/osu); mostly outside that repository, though I have a couple contributions.

### Activity

I usually just work on whatever I feel like and I like learning new things with each project.

Some notable repositories:
 - [otdb](https://github.com/Sheppsu/otdb) - a tournament database website with tournament, mappool, and user data displayed neatly with search/sort/filter functionality: https://otdb.sheppsu.me
 - [CTA website](https://github.com/sheppsu/achievement-hunt-site) - website for an osu! event I host annually called [Capture The Achievement](https://cta.sheppsu.me/)
 - [osu.py](https://github.com/Sheppsu/osu.py) - a Python api wrapper for osu! api v2.
 - [discord-ext-listening](https://github.com/Sheppsu/discord-ext-listening) - voice receive extension for [discord.py](https://github.com/rapptz/discord.py) built on multiprocessing and designed to be flexible. The repository is old and I don't update it, so I'm not even sure if it still works. Still though, I think it's worth mentioning.
 - [Offline chat bot](https://github.com/Sheppsu/offlinechatbot) - a Twitch bot written in Python that runs in a few offline chats, but originating in [BTMC](https://www.twitch.tv/btmc)'s offline chat.
 - [Offline chat bot site](https://github.com/Sheppsu/offlinechatbot-site) - the site for offline chat bot. Has docs and other fun stuff.
 - [sdvx_memory_reader](https://github.com/Sheppsu/sdvx_memory_reader), C library for reading memory of sdvx exceed gear to get certain data. I also made [sdvx_rich_presence](https://github.com/Sheppsu/sdvx_rich_presence) which builds off of the memory reading library to implement a discord rich presence
 - [AMQ-7TV-Chat](https://github.com/Sheppsu/AMQ-7TV-Chat) - a tapermonkey script that adds 7TV emotes to [AMQ](https://animemusicquiz.com/) chat.
 - [amq-fsrs](https://github.com/sheppsu/amq-fsrs) - A scuffed version of AMQ that runs locally (still connecting to the actual AMQ site over socket.io), but implements FSRS to help learn songs similar to Anki (but not as good rn).
 
Discord server if you want to contact me or talk about one of my projects for whatever reason: https://discord.gg/uVmrN9zQ99
